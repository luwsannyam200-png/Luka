# /weekly: долоо хоногийн үлдэгдлийн тайлан

Хэрэглэгчтэй **монгол хэлээр** харилц. Хэрэглэгч програмчлалын мэргэжилтэн биш тул нэр томьёог энгийнээр тайлбарла.

## Файлууд (Google Drive → Energy Resource → Weekly)

| Файл | Нэрний хэв маяг | Юу авах вэ |
|---|---|---|
| Weekly draft | `Weekly draft*.xlsx` | Загвар. Хамгийн сүүлийн sheet-ийг хуулна |
| Oracle үлдэгдэл | `MM-DD үлдэгдэл.xlsx` (хамгийн шинэ нь) | УХ = `TL*` ба `ТЛ ши` (кирилл), ЦХ = `TKH*` ба `TG_TKH-Sub` (хэрэглэгч баталсан). Бүх sheet-ээс хайна. Урд нь TL_TKH хураангуй sheet нэмсэн файл ч болно. Эх тайлангүй бол `Item Code / TL / TKH` хураангуйг шууд уншина |
| Parts and oil | `Parts*` | Parts and oil багана |
| Очлуур од | `Очлуур*` / `Ochluur*` | Очлуур од багана |
| AODE | `AODE*` / `Аодэ*` | AODE багана |

`_TL_TKH`, `(1)` гэх мэт урьд нь Claude-ын үүсгэсэн файлуудыг эх файл болгож **бүү** ашигла.

## Алхмууд

1. **Файл олох.** `search_files` ашиглан `title = 'Weekly'` хавтсыг ол (эцэг хавтас нь `Energy Resource`). Дараа нь `parentId = '<id>'` гэж хайж жагсаа. Олдсон, олдоогүй файлуудыг хэрэглэгчид товч жагсааж хэл. Нийлүүлэгчийн файл дутуу байж болно.
2. **Огноо.** Шинэ sheet-ийн нэр нь өнөөдрийн `MM.DD` (жишээ нь `09.26`). Хэрэглэгч өөр огноо хэлсэн бол түүнийг ашигла.
3. **Татаж авах.** Scratchpad хавтас руу `download_file_content`-ээр татна.
   - Том файлын үр дүн дискэнд хадгалагдана → `jq -r .content <saved>.txt | base64 -d > file.xlsx`
   - **Жижиг файл** (~50KB-аас бага) бол base64 шууд хариунд ирж, дискэнд хадгалагдахгүй. Base64-ийг гараар бүү хуул. Оронд нь `read_file_content`-ээр текст хувилбарыг уншиж, **загвар sheet дээрх item code-уудад** харгалзах үлдэгдлийг `manual.json` болгон бич: `{"Очлуур од": {"4016150400048": 167}}`. Мянгатын таслалыг (`"1,598."` → 1598) анхаар. Хэрэглэгчид энэ тоонуудыг гараар хуулсан гэдгийг хэл.
4. **Бүтээх.** Анхны Weekly draft-ийг хэзээ ч openpyxl-ээр хадгалж болохгүй. Энэ нь хуучин sheet-үүдийн гадаад холбоостой томьёоны утгыг устгадаг. Үргэлж скриптийг ашигла:
   ```bash
   python3 .claude/skills/weekly/scripts/build_weekly.py \
     --draft draft.xlsx --stock stock.xlsx --date MM.DD --out "Weekly draft_MM.DD.xlsx" \
     [--parts parts.xlsx] [--ochluur ochluur.xlsx] [--aode aode.xlsx] [--manual manual.json]
   ```
   Скрипт хамгийн сүүлийн sheet-ийг загвар болгон хуулж, УХ, ЦХ, нийлүүлэгчийн багануудыг шинэчилнэ. TL Warehouse, Нийт агуулах, All warehouse баганыг томьёо болгоно. Файлгүй нийлүүлэгчийн баганыг хоосон, шар өнгөтэй үлдээнэ. Үр дүнгийн JSON-д өмнөх долоо хоногийн утгууд (`prev`) орсон байна.
   - Draft-д ийм нэртэй sheet аль хэдийн байвал скрипт зогсоно. Хэрэглэгчээс тухайн sheet-гүй хуучин draft-ийг асуу.
5. **Шалгах (заавал).**
   ```bash
   python3 .claude/skills/weekly/scripts/verify_weekly.py --original draft.xlsx --new "Weekly draft_MM.DD.xlsx" --date MM.DD
   ```
   `OK` гарахаас нааш файлыг хэрэглэгчид **бүү** илгээ. Үүнээс гадна 2–3 сэлбэгийг эх файлаас гараар тулгаж шалга.
6. **Илгээх.** `SendUserFile` (display: attach). Drive руу шууд оруулах боломжгүй (хэт том). Хэрэглэгч өөрөө татаж аваад Weekly хавтсанд оруулна.

## Тайлан (хариултын бүтэц)

1. Аль файлуудыг ашигласан, аль нийлүүлэгч дутуу байгаа (шар багана)
2. Өмнөх sheet-тэй харьцуулсан **мэдэгдэхүйц өөрчлөлт**: УХ+ЦХ 0 болсон, 30%-иас дээш буурсан, эсвэл их орлого орсон сэлбэгүүд
3. **Анхааруулга**: All warehouse < 0.5 (ЗБН-ий 50%-иас бага) сэлбэгүүд
4. Үргэлж сануулах зүйлс:
   - **Захиалгын хэмжээ, РО дугаар, Орлогод аваагүй** багана өмнөх sheet-ээс хуулагдсан. Эдгээр нь долоо хоног бүр өөрчлөгддөг тул хэрэглэгч шинэчлэх хэрэгтэй.
   - Нийлүүлэгч дутуу бол **Нийт агуулах / All warehouse** дутуу тоо харуулна.
   - Файл нээхэд "Update links" гэж асуувал **Don't Update** дарна.

## Хориглох зүйл

- Хуучин sheet-ийн нэг ч нүдийг өөрчлөхгүй. Шинэ sheet зөвхөн нэмэгдэнэ.
- Компанийн өгөгдлийн файл (xlsx, хүний нэр, утас) репозиторт commit хийхгүй. Бүх ажлын файл scratchpad-д байна.
- Тоо таамаглахгүй. Олдоогүй мэдээллийг хоосон үлдээж, хэрэглэгчид хэлнэ.

## Офлайн хувилбар

Интернэтгүй хувилбар нь `tools/Heregsel.html` → **📦 Weekly үлдэгдэл** таб. Хөтчөөр нээгээд файлуудаа чирж оруулна. Логик нь `tools/src/weekly-core.js`, энэ скрипттэй ижил. Нэгийг өөрчилбөл нөгөөг нь мөн өөрчилж, `python3 tools/build.py --jszip ... --xlsx ...`-ээр HTML-ийг дахин бүтээнэ (npm: jszip@3.10.1, xlsx@0.18.5).
