# /zasvariin-huselt: засварын хүсэлтийн тайлан

Хэрэглэгчтэй **монгол хэлээр** харилц. Хэрэглэгч програмчлалын мэргэжилтэн биш.

## Үр дүн (нэг Excel файл, багийн эцсийн тайлантай яг ижил — илүү дутуу sheet байхгүй)

| Sheet | Агуулга |
|---|---|
| **Sheet1** | Pivot хэлбэр: A1 "Count of Засварын төрөл", B1 "Column Labels", A2 "Row Labels". Мөр: Засварын байршил → Үйлчилгээ (хоосон үйлчилгээ "(blank)", сүүлд). Багана: хүсэлт гаргасан өдөр (`13-Oct`), "Grand Total". |
| **Sheet2** | D5-аас эхэлнэ. Гарчиг "Засварын төрөл", өдрүүд, "Хүсэлт". Байршил (үйлчилгээтэй бол хар хөх 2F5597, тод цагаан), үйлчилгээ (цайвар хөх 8FAADC). Үйлчилгээгүй байршил (жишээ нь Замд) цайвар хөх, энгийн. Гарчиг, "Нийт хүсэлт" мөр 203864. Хүрээ нимгэн хар, D баганын өргөн 15.89. |
| Эх sheet | Mine2TL-ийн анхны өгөгдөл, **өөрчлөлтгүй** |

Хоосон үйлчилгээ байршлын тоонд орно, Sheet2-т тусдаа мөр болж гарахгүй. Байршил, үйлчилгээ монгол цагаан толгойн дарааллаар эрэмбэлэгдэнэ.

## Имэйлийн драфт (хэрэглэгч өдөр бүр илгээдэг)

```
Өглөөний мэнд.

Тээврийн хэрэгслийн засварын хүсэлтийн мэдээлэл хүргүүлж байна.
УХ-Засварын хэсэгт N чирэгч засвар хүлээлгэнд байна.     ← `ukh_agregat` (байршил Ухаа худаг + үйлчилгээ Агрегат) жагсаалтыг хэрэглэгчид харуулж, N-г хэрэглэгчээс асуу; 0 бол мөрийг орхи

Нийт хүсэлт-<requests>
Т/Х -ийн тоо-<tech_count>

<Sheet2-ийн хүснэгт>
```
`tech_count` = давхардаагүй Техникийн №. `duplicates`-д нэг машинаас ирсэн олон хүсэлт байвал жагсааж хэлнэ.

## Алхмууд

1. Drive-аас `засварын хүсэлт` хавтсыг `search_files`-ээр олж, хамгийн шинэ `.xlsx`-ийг сонго.
2. `download_file_content`-ээр scratchpad руу тат.
   - Том файл дискэнд хадгалагдана → `jq -r .content <saved>.txt | base64 -d > input.xlsx`
   - **Жижиг файл** (~50KB-аас бага) бол base64 хариунд шууд ирнэ. Гараар бүү хуул. Энэ тохиолдолд **Heregsel.html**-ийг ашиглахыг зөвлө (доор). Эсвэл `read_file_content`-ийн текстээс засварын төрөл, техникийн №, байршил, үйлчилгээ, тайлбар, төлөвлөгөөт цаг, ачаатай, хүсэлтийн огноог хуулж, **жолоочийн нэр, утсыг оруулахгүйгээр** ижил гарчигтай xlsx үүсгэ. Мөрийн тоо файлын төгсгөлийн нийт тоотой таарч байгааг шалга.
3. Ажиллуул:
   ```bash
   python3 .claude/skills/zasvariin-huselt/scripts/zasvar_report.py --input input.xlsx --out "Zasvaryn_huselt_MM.DD.xlsx"
   ```
   MM.DD = файлын хамгийн сүүлийн хүсэлтийн өдөр.
4. **Шалга:** JSON дахь `requests`, `by_location`, `by_service`, `by_day`-ийг эх файлтай тулга. Sheet2 дээр мөр бүрийн нийлбэр "Хүсэлт" баганатай, "Нийт хүсэлт" нь хүсэлтийн тоотой таарах ёстой.
5. `SendUserFile` (display: attach). Файлын нэрийг латинаар өг. Кирилл нэртэй файлыг хөтөч татахдаа "download" болгодог.
6. Имэйлийн драфтыг (дээрх хэлбэрээр) бичиж өг, давхардсан техникийг жагсаа.

## Офлайн хувилбар

`tools/Heregsel.html` → **🔧 Засварын хүсэлт** таб. Логик нь `tools/src/zasvar-core.js`, энэ скрипттэй ижил үр дүн гаргана. Нэгийг өөрчилбөл нөгөөг нь мөн өөрчилж, `python3 tools/build.py --jszip ... --xlsx ...`-ээр дахин бүтээ.
