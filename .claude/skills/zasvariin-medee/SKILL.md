# /zasvariin-medee: засварын мэдээ

Хэрэглэгчтэй **монгол хэлээр** харилц. Үр дүн нь хэрэглэгчийн гараар хийсэн "ЗМ 27.xlsx"-тэй ижил байх ёстой. Энэ нь 180 мөр × 21 баганаар тулгаж шалгасан. Цорын ганц зөрүү нь хэрэглэгчийн хүсэлтээр "АЧИГЧ" биш **"Ачигч"** гэж бичдэг.

## Алхмууд (хэрэглэгчийн гар арга)

| # | Нөхцөл | Үйлдэл |
|---|---|---|
| 1 | — | "Хэсгийн №" баганыг устгана |
| 2 | Засварын төрөл = Дуудлага | Байршил → механикийн байршил, Үйлчилгээ → Дуудлага |
| 3 | — | Доод талын нийт дүнгийн мөрийг устгана |
| 4 | Төлөвлөгөөт | Үйлчилгээ → Дис тайлбар руу, Үйлчилгээ → Төлөвлөгөөт |
| 5 | Жолооч хоосон | Үйлчилгээ → Ачигч |
| 5а | Төлөвлөгөөт + Ачигч + Дис тайлбар хоосон | Мех тайлбараас ТҮ-г **зөвхөн санал** болгоно. Хэрэглэгч батлавал бичнэ, үгүй бол хоосон |
| 6 | Байршил = Замд | Байршил → механикийн байршил |
| 7 | — | Шалгалт: Ачигч/Дуудлага/Төлөвлөгөөт байгаа, үйлчилгээ хоосон мөргүй, байршил зөвхөн УХ/ЦХ |
| 8 | Улаан = цэнхэр (дуусаагүй) | Цэнхэр мөрүүд эхэнд. Дууссан = эхний саарал мөрийн өдөр **06:00** |
| 9–14 | — | **Дууссан огноо** = зарцуулсан цаг, **Засварын код** = хүлээсэн цаг, **Машины төлөв** = нийт цаг (цагаар). Томьёо нь ЗМ 27-тэй ижил |

Өнгө: саарал = дууссан, цэнхэр = үргэлжилж байна, улаан = засварчин оруулаагүй. Улааныг цэнхэр болгоно.

## Ажиллуулах

1. Drive-аас `засварын мэдээ` хавтсыг `search_files`-ээр олж, хамгийн шинэ эх файлыг (Mine2TL-ийн экспорт, "Хэсгийн №" баганатай) `download_file_content`-ээр scratchpad руу тат (`jq -r .content … | base64 -d`).
2. **Эхлээд шалгах горимоор** ажиллуул:
   ```bash
   python3 .claude/skills/zasvariin-medee/scripts/medee_process.py --input src.xlsx --check-only
   ```
3. **Механикийн байршлыг хэрэглэгчээс лавла.** `mechanics` хэсгийг хүснэгтээр харуул: механик, автоматаар танигдсан байршил, тоо. Шинэ механик, эсвэл хэрэглэгч засах бол `mech.json`-д бич: `{"нэр": "Цагаан хад"}`. `mechanics_unknown` хоосон биш бол заавал асуу.
4. **5а-ийн саналыг лавла** (`tu_suggestions`). Батласан утгыг `tu.json`-д бич: `{"6494MMA": "ТҮ-2"}`. Батлаагүй бол хоосон үлдэнэ.
5. Ажиллуул:
   ```bash
   python3 .claude/skills/zasvariin-medee/scripts/medee_process.py --input src.xlsx --out "ZM_DD.xlsx" [--mech mech.json] [--tu tu.json]
   ```
   Алдаа гарвал (`error`) файл үүсэхгүй. Шалтгааныг хэрэглэгчид тайлбарла.
6. JSON-ийн `services`, `locations`, `blue`, `gray`, `warnings`-ийг товч тайлагна. `SendUserFile` (display: attach), файлын нэр латинаар.

## Тэмдэглэл

- Цэнхэр мөрийн "Механик" ба "Хүлээсэн цаг" баганад хэрэглэгчийн аргын завсрын томьёо үлддэг. Хүлээсэн цаг нь утгагүй том тоо байдаг. Хэрэглэгч "цаашид хэрэглэгдэхгүй" гэсэн тул хэвээр үлдээнэ.
- "Цагийн зөрүү", "Засварчдын нэрс" нь Mine2TL-ээс татах мөчөөс хамаарч өөрчлөгддөг. Энэ нь алдаа биш.
- Жолооч, засварчдын нэр, утас бүхий файлыг репозиторт хадгалахгүй.
- Интернэтгүй хувилбар: `tools/Heregsel.html` → **📋 Засварын мэдээ** таб (`tools/src/medee-core.js`). Энэ скрипттэй нүд бүрээр ижил гаралт өгдөг. Нэгийг өөрчилбөл нөгөөг нь мөн өөрчилж, HTML-ийг `tools/build.py`-аар дахин бүтээнэ.
- Хэрэглэгч дараагийн алхмуудыг (тайлан, pivot) нэмж тайлбарлах гэж байгаа.
